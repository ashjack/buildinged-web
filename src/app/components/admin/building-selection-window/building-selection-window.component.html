BuildingEd quick start

Create a building from a room and material preset, or upload an existing .tbx file.

Draw rooms, add doors and windows, then furnish your building with the editor tools. Use the save button in the editor to download your .tbx file.

The browser keeps a recovery copy of your current building. Download your work to keep a separate copy. Shared saving and live sessions are planned for a later update.
