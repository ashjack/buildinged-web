Getting started

Create a building from a template, or open an existing .tbx file.

Draw rooms, add doors and windows, then furnish with the editor tools. Use the save button in the editor to download your .tbx.

Your browser keeps a recovery copy of the current building, but download your work to keep a separate copy.
